## Reference-year decision

The professional and establishment dictionaries identify December 2023 in their source field, while the catalog and the dictionaries’ year columns say 2024. The files have no observation-date column. The project labels these as an undated 2023/2024 resource snapshot, keeps 2024 population as its main denominator, and checks 2023 population. The discrepancy is unresolved, not silently corrected.

The hospital-bed file has an explicit period column; only 2024 records are retained. Its dictionary appears to be a general snapshot dictionary and cannot establish the meaning of missing municipal rows. These rows remain missing.

The mortality dictionary defines infant deaths and births by municipality of residence and occurrence date: [official dictionary](https://repositorio.seade.gov.br/dataset/b39bd92e-cda6-4062-aca7-68b4597affe4/resource/e242b72e-691e-47a6-8a5a-b8b72b79cb28/download/dic_variaveis_obitosinfantis_periodo.csv). It was inspected to confirm denominator alignment.

## Numeric and missing-value conventions

Seade numeric CSV fields use decimal commas and may use dots as thousands separators. SIDRA JSON values use numeric decimal points. The sanitation count table’s dash cells are treated as zero; suppressed or unavailable values remain missing and fail the required-category check. Mutually exclusive sanitation counts reconcile exactly with each municipal total. No source absence is inferred as a zero.

## Updating the study

`python run.py fetch` preserves the frozen source manifest and checks hashes. Missing files are recovered only if the provider still serves the same bytes. `python run.py fetch --refresh` downloads current files into `data/latest/`. Those files must be audited before constructing a new study version. Copying new files into `data/raw/` without updating and reviewing provenance intentionally fails verification.
